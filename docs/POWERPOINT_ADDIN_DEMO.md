# Demo PowerPoint Add-in

Mở task pane, đăng nhập tài khoản test, tạo session PowerPoint, chọn Auto/VI/EN. Chọn đúng một
slide có text, nhập yêu cầu rút gọn tiêu đề và bấm Create proposal. Chỉ ra provenance rút gọn và
nhấn mạnh slide chưa đổi. Bấm Apply, đối chiếu text trên slide. Đăng xuất để xóa token khỏi RAM.

Nếu chỉ chạy task pane/browser hoặc Office mock, phải gọi đúng là kiểm chứng task pane/mock;
không gọi đó là native PowerPoint Desktop.
