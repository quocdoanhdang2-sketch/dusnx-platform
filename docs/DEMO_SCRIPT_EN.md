# EN demo script — 8 minutes

Introduce DUSN-X and the Web → Gateway → FastAPI → router/state/memory → Ollama path. Sign in with
a test account, save a decision, propose and confirm an update, then recall it in a new session.
Open the opt-in Inspector and explain its filtered routing, state checksum and provenance. Ask in
English, switch the preference to Vietnamese, and ask again. In PowerPoint, create a proposal from
the selected slide and apply it only after confirmation. Close with the trained router checkpoint,
unpromoted v1 candidate, untrained v2 candidate, draft v2 data and unopened holdout v3.
